# Qwen Status (Windows)

로컬 Qwen 서버의 상태를 작업 표시줄 알림 영역에서 확인하는 Windows 앱입니다. 서버가 꺼짐·준비 중·대기·작업 중인지 표시하고, vLLM 호환 `/health`·`/metrics`에서 속도와 세션 토큰을 읽습니다. NVIDIA GPU가 있으면 VRAM·온도도 보여줍니다.

밝은 상태창에서 서버 상태·누적 처리량·실시간 속도와 최근 입력·출력을 한 화면에 표시합니다. 직접 대화는 별도 창에서 대화 목록, 이전 기록, 진행 중 답변, 중단과 삭제를 지원합니다. 같은 대화에서는 공통 대기열의 동일한 세션 ID를 사용해 앞선 맥락을 이어갑니다. 대화 원문은 `%LOCALAPPDATA%\QwenStatus\chat-history.json`에도 저장되므로 PC를 공유한다면 개인정보에 주의하세요.

공통 대기열을 연결하면 최근 요청의 입력/출력, 첫 토큰까지 걸린 시간, 출력 속도, 누적 토큰과 7일 그래프, 최근 100건의 작업 내역을 볼 수 있습니다. 원문은 첫 실행에서 가려져 있으며 상태창에서 표시 여부를 바꿀 수 있습니다. **누적 토큰은 로컬 Qwen 처리량이지 OpenAI 토큰 절약량이 아닙니다.**

`분석 센터`에는 요청의 대기·첫 토큰·생성 타임라인, 서버/대기열 연결 진단, vLLM·ninfer 토큰 테스트 결과 비교, 출처별 사용량, 원문이 없는 PNG 공유 카드가 있습니다. 트레이 메뉴의 `작은 상태창`은 서버 상태·처리/대기 건수·속도·GPU 상태만 별도로 보여줍니다. 분석 센터와 작은 상태창은 서버를 자동으로 시작하거나 중지하지 않습니다.

분석 센터의 `대기열`은 현재 실행·대기 요청의 출처와 경과 시간을 보여줍니다. 상태창에서 시작한 직접 대화만 여기서 취소할 수 있으며, 다른 앱의 요청과 Qwen 서버는 중단하지 않습니다. 요청별 상세 목록은 공통 대기열의 `/ui/queue` API가 있어야 표시됩니다. 기존 게이트웨이는 건수만 표시될 수 있습니다.

`기록 정리`에서는 완료된 오래된 요청의 원문 파일을 선택 기간·출처별로 삭제할 수 있습니다. 삭제 전에 건수와 토큰 수를 미리 보여주고 확인을 받습니다. 토큰·날짜·출처·속도 등 원문 없는 집계는 `%LOCALAPPDATA%\QwenStatus\archived-usage.json`에 남겨 누적 사용량을 유지합니다. 집계 파일도 지우면 과거 누적치는 복원할 수 없습니다. 대화 세션은 정리 대상이 아닙니다.

`노트북 효율`은 NVIDIA NVML 전력 센서가 지원될 때 GPU 전력을 250ms 간격으로 읽고, 공통 대기열의 요청 시작·종료 시각에 맞춰 요청별 에너지를 추정합니다. 유휴 전력 샘플이 충분하면 이를 제외한 J/출력 토큰을 표시합니다. 샘플이 요청 시간을 덮지 못하거나 센서·사용량 기록이 없으면 수치를 만들지 않습니다. 전체 PC 전력이나 전기요금은 아닙니다.

`성능 추세`는 최근 7일/30일의 날짜·출처·백엔드별 요청 수, 대기 P95, 첫 토큰 P95, 생성 속도 중앙값과 실패·취소 건수를 계산합니다. 현재 서버가 KV 캐시·선점·접두 캐시 메트릭을 제공하면 함께 보여줍니다. 과거 기록에 백엔드 정보가 없으면 `미기록`으로, 현재 백엔드가 해당 지표를 내지 않으면 `미제공`으로 표시합니다.

처음 실행하고 설정 파일이 없으면 연결 안내 화면이 열립니다. 트레이 메뉴의 `연결 설정`에서도 로컬 서버·공통 대기열 주소와 기록 폴더를 확인하고 저장할 수 있습니다. 저장한 설정은 상태 앱 재시작 후 적용됩니다. `중요 알림`은 서버 연결 끊김·준비 완료, 반복 측정된 높은 GPU 온도, 실패한 요청만 알려줍니다. 트레이 메뉴에서 끌 수 있습니다.

`백엔드 비교`에서는 같은 프로필 결과 두 개를 선택해 첫 토큰 시간·생성 속도·정확성 검사 통과 수를 비교할 수 있습니다. 새 `quick` 토큰 테스트에는 간단한 정확성 검사가 포함되며 속도 평균에는 넣지 않습니다. 기존 테스트 결과에 정확성 수치가 없으면 `검사 없음`으로 표시합니다. 검사는 서버를 자동 실행하지 않으며, 각 백엔드에서 직접 토큰 테스트를 수행해야 합니다.

`업데이트`는 이 저장소의 `main`을 확인해 새 소스를 컴파일하고 핵심·분석·기록·연결 자체 검사를 통과하면 백업 후 적용합니다. 실패하면 기존 파일은 유지하며, 문제가 있으면 마지막 백업으로 되돌릴 수 있습니다. 상태 앱을 재시작해야 새 소스가 적용되고 Qwen 서버는 그대로 둡니다. GitHub 체크아웃이 앱 폴더이거나 옆의 `QwenStatus-public` 폴더에 있어야 합니다. 현재는 소스 실행 사용자용 기능으로, 서명된 설치 파일의 자동 업데이트 기능은 아닙니다.

백엔드 비교는 같은 프로필로 각각 토큰 테스트를 실행한 후 `백엔드 비교`에서 **현재 백엔드와 최근 결과를 확인하여 등록**합니다. 결과 JSON의 경로와 백엔드 표시는 `%LOCALAPPDATA%\QwenStatus\benchmark-index.json`에 저장되며, 모델 출력 원문은 이 파일로 복사하지 않습니다. 워밍업 결과가 실제 콜드 스타트를 뜻하지는 않습니다. 같은 모델·설정·입력 조건에서만 속도를 비교하세요. 오래된 `client` 기록은 연결 앱을 더 세분할 정보가 없어 `연결 앱`으로 합산합니다.

## 현재 범위

이 저장소에는 상태 앱의 소스만 있습니다. Qwen 모델, vLLM/ninfer, 공통 대기열, Hermes, 서버 시작·종료 스크립트는 포함하지 않습니다. 서버만 연결해도 상태·GPU·세션 지표를 볼 수 있습니다. 대기열이 없으면 작업 기록과 직접 대화·토큰 테스트는 사용할 수 없고, 앱에 연결 안내가 표시됩니다. 시작·종료 버튼은 해당 스크립트가 앱 폴더에 있을 때만 활성화됩니다. 서버의 시작과 종료는 사용자가 직접 결정합니다.

## 빌드

Windows의 .NET Framework 4 C# 컴파일러를 사용합니다. `build.cmd`를 실행하면 같은 폴더에 `QwenStatus.new.exe`가 만들어집니다. 빌드 스크립트는 서버를 시작하거나 중지하지 않습니다.

개인 PC에서는 Windows PowerShell 5.1로 소스를 메모리에서 컴파일해 실행할 수도 있습니다. 같은 폴더의 `run-source.ps1`을 `powershell.exe -NoProfile -STA -ExecutionPolicy RemoteSigned -File .\run-source.ps1`로 실행하면 새 QwenStatus EXE를 만들지 않습니다. `RemoteSigned`는 이 프로세스에만 적용되며 Smart App Control이나 Defender 설정을 바꾸지 않습니다. 앱은 스크립트 폴더의 설정·보조 파일을 사용합니다. 이 방식도 PC의 스크립트 실행 정책에 따라 차단될 수 있으므로 일반 배포용 설치 방법은 아닙니다.

생성된 EXE는 **코드 서명이 없습니다.** 조직의 App Control 또는 Windows Smart App Control 환경에서는 실행이 차단될 수 있습니다. GitHub에서 내려받았다는 사실만으로 실행 파일에 신뢰 서명이 붙지는 않습니다. 보안 정책을 해제해 실행하는 방법은 권장하지 않습니다.

## 설정

`settings.example.json`을 `%LOCALAPPDATA%\QwenStatus\settings.json`으로 복사해 사용합니다. 설정을 바꾼 뒤 앱을 다시 실행하세요. 서버는 기본적으로 `127.0.0.1:18021`, 공통 대기열은 `127.0.0.1:18022`를 사용합니다. `gatewayDirectory`와 `jobsDirectory`의 상대 경로는 앱 폴더(EXE 또는 소스 실행 스크립트의 폴더)를 기준으로 합니다. 대화용 `uiUrl`은 보안상 로컬 HTTP만 허용합니다. 토큰 파일은 설정에 넣지 않고 공통 대기열의 `ui-token.txt`에서 읽습니다.

직접 대화는 해당 공통 대기열의 UI API와 `ui-token.txt`가 필요합니다. Hermes 버튼은 `%LOCALAPPDATA%\hermes\node\hermes.cmd`가 설치됐을 때 동작합니다. 토큰 테스트는 공통 대기열의 `token-test.mjs`와 Node.js가 필요합니다. Node.js 위치가 자동으로 발견되지 않으면 `QWEN_NODE_EXE` 환경 변수를 지정할 수 있습니다.

서버 시작·종료 스크립트가 필요하면 자신의 환경에 맞춘 `start.sh`·`stop.sh`를 EXE 옆에 직접 배치해야 합니다. 개인 PC의 스크립트와 경로는 이 저장소에 포함하지 않았습니다.

## 데이터와 개인정보

앱의 설정·진단 파일은 `%LOCALAPPDATA%\QwenStatus`에 저장됩니다. 작업 원문과 사용량은 연결한 공통 대기열의 `requests` 폴더에서 읽으며, 화면에서 원문을 가려도 원본 파일은 삭제되지 않습니다. 공개 저장소나 이슈에 `requests`, `jobs`, 토큰 파일, 인증 파일, 로그를 올리지 마세요.

현재는 기술 사용자용 소스 공개 준비본입니다. 일반 사용자용 설치 파일, 신뢰 코드 서명, 통합 설치 마법사는 아직 제공하지 않습니다.
