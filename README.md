# Qwen Status (Windows · Strata FN)

로컬 **Strata FN(Qwen3.8 Flash Next SC117 IQ3_XXS / IQ2_XS)**의 상태·직접 대화·AI 작업 위임을 Windows 알림 영역에서 관리합니다. `/health`의 실제 모델·loaded·문맥 용량과 JSON `/metrics`를 읽고, NVIDIA GPU가 있으면 VRAM·온도·지원되는 전력 지표를 표시합니다.

현재 제품은 **Strata 전용**입니다. 지원하지 않는 백엔드 설정은 오류로 안내하며 다른 엔진으로 자동 실행하거나 이전 설치를 삭제·변환하지 않습니다. 과거 요청·벤치마크의 엔진 이름은 기록으로 계속 읽을 수 있습니다.

## 설치와 연결

[처음 사용자 설치 안내](INSTALL.md) · [다른 AI에게 전달할 설치 요청](AI-INSTALL-PROMPT.md) · [런타임/MCP 안내](runtime/README.md)

설치 도우미는 두 가지 구성만 제공합니다.

- **기존 Strata FN 연결**: 실제 HTTP loopback URL을 명시하고 모델·유효 문맥을 확인합니다. 기본적으로 기존 서버의 시작·종료·설정은 제어하지 않습니다. 명시적 외부 제어 스크립트를 설정한 경우에만 기존 자동 관리자에게 재개/일시정지를 요청할 수 있습니다.
- **Strata FN · 네이티브 준비**: 이미 준비한 고정 Strata 소스·전용 Python/CUDA 의존성·공식 엔진·SC117 GGUF/pack/tokenizer/MTP 설정을 검증하고 관리 설정을 만듭니다. IQ3_XXS / IQ2_XS를 선택하고 문맥·workers·RAM·prefill을 조정할 수 있습니다.

네이티브 준비는 **엔진·모델 전체 자동 다운로드나 새 GPU PC 원클릭 설치가 아닙니다.** Node.js 22가 없으면 공식 portable 배포본만 체크섬 확인 후 준비하며, Hermes는 별도 선택입니다. 앱 연결 설정 변경은 기본 해제이고 선택한 경우에만 기존 설정을 백업합니다. 준비만으로 모델·대기열·Telegram을 시작하지 않습니다.

관리 Strata는 `127.0.0.1:18021`, 공통 대기열은 `127.0.0.1:18022`를 사용합니다. 기존 서버가 8088 등 다른 포트라면 그 주소를 명시하세요. 현재 실행 중인 서버를 자동으로 바꾸지 않습니다. **게이트웨이는 텍스트·도구 호출 전용**이며 upstream의 이미지 광고와 무관하게 이미지 입력을 거절합니다.

## 주요 기능

- 상태창: 준비 중/대기/작업 중/연결 끊김, 서버 토큰·속도, 처리·대기 건수, 최근 입력·출력. 원문은 기본 가림입니다.
- 직접 대화: 대화 목록·검색·이름 변경·Markdown 저장·답변 복사, 입력 초안 보존, 응답 중단·대화 삭제. 같은 세션에서는 이전 맥락을 이어갑니다. 연결 복구 시 기존 요청을 조회하며 질문을 자동 재전송하지 않습니다.
- 공통 대기열: FIFO, 동시 생성 1개, 직접 대화·MCP·Hermes의 공통 요청 기록과 사용량. 모델이 꺼져 있거나 unloaded이면 자동으로 켜지 않고 unavailable로 처리합니다.
- 분석 센터: 요청별 대기/첫 토큰/생성 시간, 연결 진단, 토큰 테스트 결과 비교, 출처별 사용량, 7일/30일 성능 추세, 작은 상태창, 개인정보 원문 없는 PNG 공유 카드.
- 토큰 테스트: 실제 문맥에 들어가는 quick/8k/32k/64k/224k만 제공. 출력 예약을 포함하며 자동 실행하지 않습니다. quick의 정확성 검사는 속도 평균에서 제외합니다. 워밍업은 콜드 스타트 보장이 아닙니다.
- 대기열 화면: 현재 요청의 출처·경과 시간 표시. 상태창에서 시작한 직접 요청만 취소하며 다른 앱의 요청이나 모델 서버를 중단하지 않습니다.
- 기록 정리: 완료된 오래된 요청 원문만 미리보기·확인 후 삭제하고 토큰·날짜·출처 집계를 보존합니다. 대화 세션은 정리 대상이 아닙니다.
- 노트북 효율: 지원되는 NVIDIA NVML 센서로 요청별 GPU 에너지 추정. 충분한 샘플·사용량이 없으면 수치를 만들지 않습니다. 전체 PC 전력이나 전기요금이 아닙니다.

모델·문맥·속도는 실제 서버 설정에 따릅니다. SC117 예시 최대 문맥은 262,144 토큰이지만 모든 GPU·설정의 용량이나 성능을 보장하지 않습니다. 누락된 속도·KV 지표는 `미제공`으로 남깁니다. 과거 요청에 백엔드 정보가 없으면 `미기록`입니다.

누적 처리량은 **로컬 Qwen 처리량이지 유료 AI 토큰 절약량이 아닙니다.** API 환산액은 기록된 로컬 Qwen 입력·출력 토큰에 비교용 단가를 적용한 원화 추정치이며 실제 청구액·ChatGPT 구독 절약액이 아닙니다. 기본 참고는 [OpenAI GPT-6.1 Sol 모델 요금표](https://developers.openai.com/api/docs/models/gpt-6.1-sol)의 **Standard·비캐시·272K 이하** 입력 $2.00/출력 $10.00(100만 토큰당, 2026-10-24 확인)입니다. 기본 고정 환율은 사용자가 제공한 **1 USD = 1,325원**으로, 100만 토큰당 입력 **2,650원**/출력 **13,250원**, 입력·출력 각각 100만 토큰이면 **15,900원**입니다. 실시간 또는 오늘의 환율이 아니며 자동 조회하지 않습니다.

`누적 통계 → API 단가 설정`에서 USD 입력·출력 단가와 고정 원화 환율을 변경할 수 있습니다. `%LOCALAPPDATA%\QwenStatus\api-price.json`의 `inputPerMillionUsd`·`outputPerMillionUsd`는 기존 사용자 값을 보존하고, `usdToKrw`가 없거나 유효하지 않으면 환율만 기본값 1,325를 사용합니다. 단가가 기본값과 다르면 **사용자 설정 API 비교**로 표시합니다. 캐시/쓰기·추론 과금·도구·티어 할증·세금·전기/GPU/장비 비용을 반영하지 않는 단순 비교입니다. 로컬 모델·추론·인증을 바꾸거나 유료 모델을 호출하지 않습니다.

## AI 위임 설정

트레이 우클릭 → `AI 위임 설정`에서 자동/최대/최소/수동 위임을 고릅니다. 최대 모드도 작은 작업을 억지로 위임하지 않으며 메인 AI가 설계·권한 판단·최종 검증을 맡습니다. Strata가 꺼져 있으면 직접 진행하며 자동으로 켜지 않습니다.

1. 공통 구성의 `runtime/worker/server.mjs`와 Node 경로를 지정합니다.
2. Codex·Claude Desktop·Claude Code·웹 ChatGPT/Claude 중 사용할 클라이언트를 고릅니다.
3. `로컬 프로필 저장` 후 `전달문 복사` 또는 `.md 내보내기`로 대상 AI에 안내합니다.
4. 해당 클라이언트에서 실제 도구 등록 후 작은 대표 작업의 제출·결과 회수까지 확인하세요.

프로필은 `%LOCALAPPDATA%\QwenStatus\delegation.json`, 정책은 같은 폴더의 `delegation-policy.md`에 저장됩니다. 앱 저장만으로 외부 AI 설정이나 모든 대화에 적용되지 않습니다. 웹 AI는 이 PC의 localhost에 직접 접근할 수 없으며 별도로 승인·연결한 도구가 필요합니다. 터널·권한을 자동 추가하지 않습니다. [Codex MCP](https://developers.openai.com/codex/mcp) · [Claude Code MCP](https://code.claude.com/docs/en/mcp)

## 빌드·실행·업데이트

Windows의 .NET Framework 4 C# 컴파일러로 `build.cmd`를 실행하면 `QwenStatus.new.exe`가 만들어집니다. 빌드는 모델을 실행하지 않습니다. 승인된 Windows PowerShell 5.1 환경에서는 `powershell.exe -NoProfile -STA -File .\run-source.ps1`로 소스 실행도 가능합니다. 스크립트 실행 정책이 차단하면 우회하지 말고 승인된 경로를 사용하세요.

EXE는 **코드 서명이 없습니다.** 조직 App Control·Smart App Control에서 차단될 수 있습니다. 보안 정책을 해제해 실행하는 방법은 권장하지 않습니다.

`분석 센터 → 업데이트`는 저장소의 main 소스를 컴파일·자체 검사하고 백업 후 적용합니다. 실패 시 기존 파일을 유지하고 마지막 백업으로 되돌릴 수 있습니다. Git 체크아웃이 필요하며 서명된 설치 파일 자동 업데이트는 아닙니다. 상태 앱만 재시작하고 모델 서버는 그대로 둡니다. 최초 별도 설치 폴더 업데이트 방법은 [INSTALL](INSTALL.md)을 확인하세요.

## 설정과 데이터

`settings.example.json`은 **연결 예시**입니다. 기존 설정을 통째로 덮어쓰지 말고 실제 `/health`·`/v1/models`에 맞춘 `modelId`·`contextTokens`·`serverUrl`을 적용하세요. 설정 위치는 `%LOCALAPPDATA%\QwenStatus\settings.json`이며 재시작 후 적용됩니다. 상대 기록 경로는 앱 폴더 기준입니다. UI는 로컬 HTTP만 허용하고 생성된 `ui-token.txt`를 읽습니다. 토큰 문자열을 설정에 넣지 않습니다.

직접 대화에는 같은 대기열의 UI API·토큰 파일이 필요합니다. Node 위치를 자동 발견하지 못하면 `QWEN_NODE_EXE` 또는 설치 도우미의 기록된 Node 경로를 사용합니다. Hermes는 명시적 기존 런처, 전용 관리 설치, 기본 바로가기 순서로 사용합니다. 앱이 직접 모델을 켜고 끄는 대상은 네이티브 관리 설치의 소유 프로세스뿐입니다.

### 이미 설치한 PC의 선택 설정

아래 두 키는 기본적으로 비어 있으며, 필요한 키만 기존 `settings.json`에 추가하세요. 예시는 실제 설치 경로가 아닙니다.

```json
{
  "hermesLaunchScript": "C:/AI/Hermes/Start-Local-Hermes.ps1",
  "externalControllerScript": "C:/AI/Controller/Set-AI-Mode.ps1"
}
```

- `hermesLaunchScript`: **기존의 신뢰하는 Hermes 실행 스크립트**를 지정합니다. Hermes 버튼을 누르면 관리 설치/기본 바로가기보다 먼저 `-NoLogo -NoProfile -NoExit -File`로 대화형 터미널을 열고 스크립트 부모 폴더에서 실행합니다. 기존 홈·인증·provider·폴백 설정을 복사하거나 변경하지 않습니다. 명시한 경로가 잘못되면 오류를 알리고 다른 런처로 폴백하지 않습니다.
- `externalControllerScript`: **`serverOwnership: "external"`인 Strata 연결에만** 적용합니다. 기존 단일 자동 관리자의 스크립트가 `-Mode auto`와 `-Mode paused`를 지원해야 합니다. 상태창/트레이의 `자동 관리 재개`·`자동 관리 일시정지`는 해당 모드만 숨김 실행으로 요청합니다. 앱이 엔진을 직접 시작/종료하거나 두 번째 관리자를 만들지 않습니다. 관리 설치에는 적용하지 않습니다.
- 두 값 모두 **실제로 존재하는 `.ps1` 파일의 절대 경로만** 허용합니다. 따옴표·줄바꿈·추가 인수는 허용하지 않습니다. 비어 있거나 생략한 경우 기존 동작을 유지하며, 외부 제어 경로가 없거나 유효하지 않으면 외부 연결의 제어 버튼은 비활성입니다. 기존 `setupPowerShell`/자동 탐색을 그대로 사용하고 실행 정책 우회 옵션을 추가하지 않습니다.
- 외부 요청의 stdout/stderr는 `<managedInstallRoot>/setup-logs/controller.log`(미설정 시 앱 폴더)에 남깁니다. UI는 비동기로 응답을 기다리며, 65초가 지나면 지연을 알리되 프로세스를 강제 종료하지 않고 계속 기다립니다. 응답 대기 중에는 중복 제어를 막습니다. `auto` 성공은 즉시 모델 준비 완료를 뜻하지 않습니다. 기존 관리자가 GPU를 양보할 수 있으며, 요청 가능 여부는 계속 실제 `/health`의 `loaded`·모델·문맥 검증으로 결정합니다.

이 설정은 기존 도구 연결용이며 Hermes 설치, 자동 관리자 설치/수정 또는 인증 변경 기능이 아닙니다. 지정한 스크립트의 동작과 권한을 먼저 확인하세요.

### 앱 시작 시 대기열만 복원 (선택)

`settings.json`의 `"startQueueWithApp": true`를 **JSON boolean**으로 명시하면, Strata 백엔드이고 `managedInstallRoot`에 준비된 설치 기록과 `setup/setup.ps1`이 있을 때 최초 주 인스턴스가 `StartGateway`를 한 번 비동기로 요청합니다. 기본값은 `false`이며 생략·문자열 `"true"`·숫자는 자동 시작을 허용하지 않습니다. 준비된 외부 Strata 연결에도 사용할 수 있습니다.

기존 게이트웨이의 소유 프로세스/포트 검증과 멱등 동작을 그대로 사용합니다. 모델 서버·외부 자동 관리자·Hermes는 시작하지 않으며 upstream·소유권도 변경하지 않습니다. 두 번째 실행(`--show` 포함)은 기존 창에 신호만 보내고, polling·오프라인 시험에서는 실행하지 않습니다. 실패/30초 응답 지연은 경고창과 `<managedInstallRoot>/setup-logs/controller.log`에 알리고 자동 재시도나 강제 종료는 하지 않습니다.

로그인 시 복원이 필요하면 이 옵션을 켜고 기존 GUI 실행 경로의 바로가기를 사용자 시작프로그램에 등록할 수 있습니다. 앱은 바로가기·예약 작업·별도 시작 래퍼를 자동 생성하지 않습니다.

앱 설정·대화 원문(`chat-history.json`)·진단은 `%LOCALAPPDATA%\QwenStatus`에, 공통 요청 원문·사용량은 연결한 대기열의 `requests`에 저장됩니다. 화면에서 가려도 원본은 남습니다. 기록 감시 오류나 뒤늦은 폴더 생성은 최대 약 15초 간격으로 복구합니다. 공개 저장소·이슈·배포물에 요청·대화·jobs·토큰·인증·실행 로그를 포함하지 마세요.
